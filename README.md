## 🔌 API

ทุกหน้ายิง `POST` แบบ FormData ไป `SCRIPT_URL` พร้อมฟิลด์ `action`

| action | ใช้ตอนไหน | คืนค่า |
|---|---|---|
| `new` | ลูกค้าใหม่ลงทะเบียน | `{ok, customerId}` |
| `lookup` | ค้นหาลูกค้าเก่า | `{ok, found, customer}` |
| `upgrade` | ขอเวอร์ชันใหม่ (เวอร์ชันเก่ากว่าเท่านั้น) | `{ok}` |
| `resend` | ขอส่งอีเมลซ้ำ (เวอร์ชันล่าสุดแล้ว) | `{ok, email}` |
| `check` | ตรวจสอบสถานะ | `{ok, found, status, customer}` |

ผิดพลาดคืน `{ok:false, error:"ข้อความภาษาไทย"}`

## 🚀 Deploy

GitHub Pages เผยแพร่อัตโนมัติจาก branch `main`

```bash
git add .
git commit -m "อธิบายสิ่งที่แก้"
git push
```

รอ 1-2 นาที เว็บจะอัปเดตเอง

### ต่อโดเมนของตัวเอง

1. สร้างไฟล์ `CNAME` ที่ root ใส่ `irtgold.com`
2. ตั้ง DNS: `A` → `185.199.108.153` , `.109.153` , `.110.153` , `.111.153`
3. Settings → Pages → Custom domain → เปิด Enforce HTTPS
